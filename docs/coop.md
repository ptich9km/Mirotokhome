# Кооператив на двоих по локальной сети

Черновик, собранный за две ночи (21–22.11.2026). Ниже — как играть, что уже
работает и что сознательно упрощено.

## Как играть

1. Обе машины — с одной и той же сборкой игры.
2. Первый игрок: **Главное меню → Сетевая игра → Создать игру**. В окне
   появится ваш адрес (например `192.168.0.10`) и порт `7777`, затем кнопка
   **«Выбрать героя»**. Ждать второго игрока не нужно: игру можно начинать
   одному, второй подключится позже — хоть в уже идущий мир.
3. Второй игрок: **Сетевая игра → Подключиться**, вводит адрес и порт.
4. У каждого открывается **список своих сетевых героев** («Сетевые герои»):
   можно взять прокачанного или создать нового. Новый создаётся на обычном
   экране выбора героя и сразу записывается в ваш список.
5. Мир создаёт ведущий: у него каждый раз новый сид, поэтому карта, города и
   квесты начинаются заново. Персонаж при этом остаётся вашим.
6. Брандмауэр Windows: разрешить игре входящие подключения в частной сети.
   Порт по умолчанию — UDP 7777.

Транспорт — ENet (UDP) из Godot. «TCP/IP» здесь означает адрес и локальную
сеть; именно TCP для экшена не годится: потерянный пакет тормозил бы все
следующие.

## Персонажи между сессиями

- Файл героев лежит **на вашей машине**: `user://net_characters.json`
  (`%APPDATA%\Godot\app_userdata\Mirotokhome\`). У ведущего свои герои, у
  клиента свои — чужой файл никуда не передаётся.
- Сохраняется: класс, раса, пол, имя, внешность, выбранные навыки, книга,
  опыт и уровни навыков, изученные заклинания и книги сфер, золото, склад,
  надетая экипировка, рецепты, хотбар.
- **Мир не сохраняется**: каждая сессия — новый сид. Это решение игрока.
- Запись героя происходит при смерти (вещи потеряны — файл это помнит), при
  выходе в меню и раз в минуту во время игры.

## Мир и война между игроками

- По умолчанию между игроками **мир**: чужого героя нельзя ударить ни кликом,
  ни заклинанием, ни снарядом.
- Объявить войну может **любой** игрок: вкладка «Отношения» в складе →
  раздел «Игроки» → «Объявить войну». Война сразу общая: её видят оба, имя
  противника над головой краснеет.
- На войне по чужому герою попадает всё: удар в упор, заклинания по площади,
  цепные заклинания, зоны и снаряды. Смерть — по общим правилам коопа.
- Новый заход — снова мир: состояние войны в файл не пишется.

## Что работает

| Механика | Как устроено |
|---|---|
| Два героя | у каждого свой персонаж, камера, склад, панели, горячие клавиши |
| Мир | генерируется по одному сиду на обеих машинах, поэтому карта, города, деревья и травы одинаковые |
| Подключение | ведущий может играть один; второй заходит в идущий мир, монстры, заспавненные до входа, ему досылаются |
| Монстры | их считает только ведущий; у второго игрока это «зеркала»: ИИ выключен, позиция и HP приходят 10 раз в секунду |
| Урон | по монстрам считает ведущий; второй игрок отправляет свой удар ведущему, а получает обратно HP |
| Лут | ведущий бросает добычу и присылает её описание второму игроку; каждый подбирает свою копию |
| Смерть | экрана «Вы погибли» нет: через 10 секунд герой возрождается у точки старта карты, **теряются только вещи** (склад и надетое), опыт, навыки, заклинания, золото и квесты остаются |
| Пауза | тактической паузы нет: пробел в сетевой игре ничего не делает, меню не останавливают мир |
| Сохранения мира | в сетевой игре отключены: слот хранит одного героя и один мир |

## Что упрощено (знать заранее)

- **Порталы между секторами закрыты** — иначе один игрок уехал бы в другой
  мир. Партия поедет вместе в следующей версии.
- **Наёмники второго игрока бессмертны**: ведущий о них не знает, монстры
  бьют только героев.
- **Квесты считаются у каждого свои**, но прогресс засчитывается по убийствам,
  которые видит ведущий.
- **События карты** (спасение путника, засада, караван) запускает ведущий;
  второй игрок видит появившихся монстров, но не текст события.
- **Готовая карта из редактора** не передаётся клиенту: он сгенерирует карту
  по сиду. Для коопа используйте обычный старт.
- **Снаряды чужого игрока** не видны на вашем экране (урон при этом проходит).

## Проверка

- `tests/net_handshake_probe.gd` — два процесса: рукопожатие ENet, фиксированный
  путь `/root/NetSession`, обмен конфигурацией мира и данными героя.
- `tests/net_game_smoke.gd` — мир в режиме ведущего: регистрация монстров,
  кодек снапшотов, поиск ближайшего героя, меню не ставит мир на паузу,
  сохранение в сетевой игре отклоняется.
- `tests/net_profile_smoke.gd` — герой переживает сессию: файл, применение в
  статики `Game`, золото/склад/экипировка после перезагрузки мира, удаление.
- `tests/net_panel_ui_smoke.gd` — окно сети в обоих режимах помещается в
  1280×800 и 1280×600, кнопки «Создать/Подключиться» и «Создать нового героя»
  на месте.
- `tests/net_coop_probe.gd` — два процесса, **горячее подключение**: ведущий
  играет один, клиент заходит в идущий мир, получает его сид, видит чужого
  героя и зеркала монстров, его удар убивает монстра на ведущем, мир/война
  переключаются и общая война доходит до ведущего, смерть без Game Over с
  возрождением у точки старта и потерей вещей.

Три набора на два процесса — не `*_smoke.gd`, поэтому `run_all.ps1` их не
запускает (обычному прогону нужен один процесс). Пуск вручную: сначала
ведущий в фоне, затем клиент, как в шапке каждого файла.
